코딩 몰라도, Claude Code (10)

막힐 때 빠져나오기

2026-07-09·조회 –

아무리 쉬워도 가끔은 막힙니다. 에러가 뜨거나, 엉뚱한 걸 하거나, 멈추고 싶을 때. 하나도 겁낼 것 없습니다. 빠져나오는 길은 늘 있습니다.

에러가 뜨면 — 복사해서 물어보기

2편부터 계속 말한 그 습관입니다. 빨간 글씨나 영어 메시지가 떠도 놀라지 마세요. 그 메시지를 그대로 복사해서 평소 쓰던 Claude(대화형)에게 붙여넣고 물어보세요.

Claude Code 쓰다가 이런 메시지가 나왔어. 무슨 뜻이고 어떻게 해결해?
(여기에 복사한 메시지 붙여넣기)

컴퓨터를 잘 다루는 사람들도 실제로 이렇게 합니다. 무엇이 틀렸는지 몰라도, 그대로 보여주고 물으면 됩니다.

하던 걸 멈추고 싶으면 — Esc

Claude Code가 뭔가 하고 있는데 멈추고 싶으면 Esc를 누릅니다. 잘못 시켰다 싶으면 언제든 멈추고 다시 말하면 됩니다.

엉뚱한 걸 했으면 — 되돌리기

방향이 어긋났으면 4편 (참고) 겁먹지 마세요에서 본 되돌리기입니다. 입력창이 빈 상태에서 Esc를 두 번 누르거나 /rewind를 입력하면 이전 지점으로 돌아갑니다. 그리고 다시, 더 구체적으로 시키면 됩니다.

말을 잘 못 알아들으면 — 더 구체적으로

원하는 결과가 안 나오면 7편 더 잘 부리는 법의 요령대로 '무엇을·어떻게·얼마나'를 붙여 다시 시켜보세요. 같은 일도 말하기에 따라 결과가 달라집니다.

그래도 안 되면

공식 문제 해결 안내도 있습니다. 무엇보다 — 막히는 건 실패가 아닙니다. 누구나 겪는 과정이고, 물어보면서 느는 겁니다.
