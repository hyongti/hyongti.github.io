코딩 몰라도, Claude Code (3)

복붙 없이 문서 요약시키기

2026-07-02·조회 –

2편에서 설치까지 끝냈습니다. 오늘은 진짜 일을 하나 시켜봅니다.

긴 문서를 통째로 요약시키기. 문서 하나 넣고 한 문장 시키면 끝입니다.

그냥 Claude로 하면 되잖아요?

됩니다. 그런데 Claude Code는 세 가지가 다릅니다.

  • 문서를 복붙 없이 폴더째로 읽습니다.
  • 결과를 파일로 저장합니다. 화면에 글로만 뜨는 게 아닙니다.
  • 문서가 여러 개여도 한 번에 합니다.

오늘은 이 차이를 손으로 느껴봅니다.

따라 하기 · 5단계

1 · 작업 폴더로 들어가 문서 넣기

까만 창을 열고 2편에서 만든 작업 폴더로 들어갑니다.

cd ~/hello_claude

혹시 "그런 폴더가 없다"는 메시지가 나오면 폴더가 아직 안 만들어진 것입니다. 2편의 mkdir ~/hello_claude부터 다시 실행하면 됩니다.

이제 그 폴더를 화면에 띄웁니다. 윈도우는 explorer ., 맥은 open . 를 입력하면 방금 그 폴더가 창으로 뜹니다.

이 명령(윈도우 explorer ., 맥 open .)은 "지금 이 폴더를 화면에 열어줘"라는 뜻입니다. 까만 창 속 폴더와 눈에 보이는 폴더가 사실 같은 곳이라는 걸 눈으로 확인할 수 있습니다.

뜬 창에 요약할 문서를 하나 끌어다 놓으세요. 회의록·보고서·긴 자료 무엇이든 좋습니다.

2 · 그 폴더에서 claude 켜기

claude

3 · 한국어로 시키기

이 폴더에 있는 문서 읽고 핵심만 열 줄 이내로 요약해줘.
요약은 새 파일로 저장해줘.

파일 이름은 몰라도 됩니다. "이 폴더에 있는 문서"면 알아서 찾습니다.

4 · 물어보면 승인

저장 전에 "이렇게 할게요, 괜찮나요?"라고 먼저 묻습니다. 내용 보고 괜찮으면 승인만 하면 됩니다.

5 · 결과 확인

폴더를 다시 열어 보면 요약 파일이 새로 생겨 있습니다. 원본은 그대로입니다.

답을 복사할 필요 없이 정리된 결과가 내 폴더에 파일로 남았습니다. 이게 대화형 Claude와의 차이입니다.

여러 개도 한 번에

문서를 여러 개 넣고 이렇게 시켜 보세요.

이 폴더의 문서들 각각 요약해서 한 파일로 모아줘.

대화형 Claude로는 파일마다 복붙해야 하는 일을, Claude Code는 폴더째 맡기면 됩니다.

요약은 대개 훌륭하지만 완벽하진 않습니다. 중요한 문서라면 원본과 한 번 맞춰 보세요. 6편에서 더 나눕니다.

안 되면

오류가 뜨면 2편의 습관 그대로입니다. 메시지를 복사해서 평소 쓰던 Claude에게 붙여넣고 물어보세요.

다음 편에서는

Claude Code가 "어디서" 일하는지, 그리고 잘못돼도 되돌리는 법. 두 가지만 짚습니다.

그러면 4편에서 뵙겠습니다.
