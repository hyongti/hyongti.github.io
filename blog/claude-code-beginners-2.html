코딩 몰라도, Claude Code (2)

설치하고 처음 말 걸어보기

2026-07-01·조회 –

1편에서는 Claude Code가 무엇이고 왜 배울 만한지를 봤습니다. 이제 말만 하지 말고 실제로 도구를 손에 쥐어보겠습니다. 오늘 할 일은 딱 두 가지입니다. 내 컴퓨터에 설치하기, 그리고 처음 켜서 말 걸어보기.

그런데 저는 이미 Claude를 쓰는데요?

이미 Claude에게 질문해 본 분이 많을 겁니다. 그 Claude와 오늘 설치할 Claude Code는 이름은 비슷하지만 하는 일이 다릅니다. 헷갈리기 쉬우니 먼저 정리하고 가겠습니다.

  • Claude (웹사이트나 앱에서 쓰는 그것) — 대화를 합니다. 물어보면 글로 답해 줍니다. 옆에서 "이렇게 하세요" 하고 알려주는 조언자에 가깝습니다.
  • Claude Code — 내 컴퓨터에서 직접 일을 합니다. 파일을 만들고, 옮기고, 정리합니다. 1편에서 말한 그 '자동화'를 실제로 해주는 것이 이 친구입니다. 옆에서 알려주는 게 아니라 내 책상 앞에 앉아 직접 정리해 주는 사람이라고 보면 됩니다.

그래서 우리는 조언을 들으려는 게 아니라 일을 시키기 위해 Claude Code를 설치하는 것입니다.

참고로 우리는 그 '까만 창'(터미널)에서 Claude Code를 씁니다. 겁먹을 필요 없습니다. 1편에서 봤듯이 명령어를 외울 일은 없습니다. 우리는 한국어로 말하고, 까만 창은 그저 Claude Code가 머무는 자리일 뿐입니다.

시작하기 전에 두 가지 확인

Claude Code는 아쉽게도 무료 플랜으로는 쓸 수 없습니다. 유료 구독(Pro 등)이나 API 계정이 필요합니다. 이미 Claude를 유료로 쓰고 계신다면 추가 비용 없이 그 구독에 포함되어 있으니 그대로 쓰시면 됩니다. 아직 유료 사용자가 아니라면 현재 요금은 claude.com/pricing 에서 확인하실 수 있습니다.

또 하나, 내 컴퓨터가 되는지 확인합니다. 대부분의 요즘 컴퓨터는 문제없습니다.

  • 윈도우: 윈도우 10 이상
  • 맥: macOS 13 이상
  • 공통: 인터넷 연결

설치하기 — 딱 한 줄

설치는 명령어 한 줄이면 끝납니다. 먼저 그 '까만 창'을 열어야 하는데, 방법은 이렇습니다.

윈도우: 시작 버튼을 누르고 PowerShell이라고 검색해서 엽니다. 그리고 아래 한 줄을 그대로 붙여넣고 Enter를 누릅니다.

irm https://claude.ai/install.ps1 | iex

맥: Command(⌘) + 스페이스바를 눌러 검색창을 열고 터미널이라고 검색해서 엽니다. 그리고 아래 한 줄을 붙여넣고 Enter를 누릅니다.

curl -fsSL https://claude.ai/install.sh | bash

잠시 기다리면 설치가 끝납니다. 설치가 끝나면 그 까만 창을 한 번 닫았다가 다시 열어 주세요. (방금 설치한 것을 컴퓨터가 새로 인식하게 하기 위해서입니다.)

제대로 설치됐는지 확인

다시 연 까만 창에 아래를 입력하고 Enter를 눌러 봅니다.

claude --version

버전 번호(예: 2.1.100 같은 숫자)가 나오면 성공입니다.

혹시 "claude를 찾을 수 없다"고 나오면

흔한 상황입니다. claude --version을 쳤는데 버전 번호 대신, "그런 명령을 찾을 수 없다"는 뜻의 메시지가 나올 수 있습니다. (윈도우는 'claude' is not recognized ... 또는 한글로 'claude'은(는) ... 인식되지 않습니다, 맥은 보통 command not found: claude 처럼 — 컴퓨터 언어 설정에 따라 영어로도 한글로도 나옵니다. 뜻은 같습니다.)

설치가 실패한 게 아닙니다. 설치는 됐는데, 컴퓨터가 방금 깐 프로그램을 아직 어디서 찾을지 모르는 것뿐입니다. 순서대로 해보세요.

  1. 까만 창을 완전히 닫고 새로 여세요. 대부분 이걸로 해결됩니다.
  2. 그래도 같은 메시지가 나오면 — 이제 이 시리즈 내내 쓸 가장 강력한 습관을 처음 써볼 차례입니다. 무엇이 잘못됐는지 몰라도 됩니다. 에러 메시지를 그대로 복사해서 평소 쓰던 Claude에게 붙여넣고 물어보세요: "나 윈도우(또는 맥) 쓰는데 Claude Code 설치하다 이 에러가 나. 어떻게 고쳐?" 문제를 그대로 보여주고 물으면, 내 상황에 맞는 정확한 방법을 알려줍니다. 컴퓨터를 다루는 사람들도 실제로 이렇게 합니다.
  3. 더 자세히 보려면 공식 설치 문제 해결 안내도 있습니다.

컴퓨터마다 환경이 조금씩 달라 생기는 아주 흔한 일입니다. 실수한 게 아니니 겁먹지 마세요.

켜기 전에 — 작업할 자리 만들기

Claude Code는 여러분이 Claude Code를 실행한 폴더 안에서 일합니다. 그래서 작업할 폴더를 정해두는 게 좋습니다. 이번 시리즈에서는 hello_claude라는 폴더를 만들겠습니다.

까만 창에 아래 두 줄을 한 줄씩 입력합니다. 복사해서 붙여넣어도 됩니다.

mkdir ~/hello_claude
cd ~/hello_claude

첫 줄은 hello_claude 폴더를 만듭니다. 앞에 붙은 ~는 '내 기본 폴더(홈)'라는 뜻이라, 어디서 입력하든 이 폴더는 늘 같은 자리에 생깁니다. 둘째 줄은 그 폴더 안으로 들어갑니다. 이제 까만 창은 그 폴더 안에 있습니다.

지금은 "Claude Code는 켜진 폴더에서 일한다"만 기억하면 됩니다. 이 두 줄이 정확히 무슨 뜻인지는 4편에서 그림처럼 쉽게 풀어드립니다.

처음 켜서 로그인하기

이제 그 폴더에서 켜봅니다. 까만 창에 아래를 입력하고 Enter를 누릅니다.

claude

처음 실행하면 로그인하라며 인터넷 브라우저가 자동으로 열립니다. 평소 쓰던 Claude 계정으로 로그인하면 됩니다. 중간에 몇 가지를 물어보면 잘 모르겠는 것은 그냥 기본값으로 넘어가면 됩니다. 로그인이 끝나고 까만 창으로 돌아오면 준비 완료입니다.

첫 인사 한마디

본격적으로 일을 시키는 건 3편에서 합니다. 오늘은 잘 연결됐는지 인사만 한번 건네 보겠습니다. 글자를 입력하는 자리에 한국어로 이렇게 쳐 봅니다.

안녕? 너는 뭘 할 수 있어?

답이 돌아왔다면 — 축하합니다. 방금 그 까만 창에서 영어도 명령어도 없이 한국어로 말을 걸었더니 답이 왔습니다. 1편에서 "알고 보면 별것 아니다"라고 한 게 바로 이것입니다.

다음 편에서는

도구를 손에 쥐었으니 이제 실제로 써볼 차례입니다. 다음 편에서는 긴 문서 하나를 Claude Code에게 통째로 요약시켜 보겠습니다. 복사 붙여넣기 없이 방금 만든 그 작업 폴더에 문서를 넣고 말 한마디로 시키는 것입니다.

그러면 3편에서 뵙겠습니다.
